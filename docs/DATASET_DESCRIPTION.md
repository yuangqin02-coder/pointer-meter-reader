# Dataset Description / 数据集说明

This document describes the datasets and result folders used in this project.

---

## 1. Raw Dataset / 原始数据集

Folder: `1.原始数据集/`

```text
1.原始数据集/
├── 分散/                          # Grouped by challenge type
│   ├── 暗光/                       # Low light
│   ├── 背景干扰/                    # Background clutter
│   ├── 高曝光/                     # Over exposure
│   ├── 倾斜拍摄/                    # Tilted camera
│   ├── 远近尺度变化/                 # Scale variation
│   └── 正常光照/                    # Normal light
└── 汇总/                           # All images merged
```

The "分散" folder is used to study robustness under different conditions.
The "汇总" folder contains all images together.

---

## 2. YOLO Detection Outputs / YOLO 检测结果

Folder: `2.yolo识别之后图片/`

Contains detection images produced by `predict_1111.py`.

---

## 3. Cropped Meter Images / 裁剪后的单表图片

Folder: `3.边框截取之后/`

Contains single-meter crops produced by `separate_1111.py`.

---

## 4. Alignment + Reading Results / 摆正+识别结果

Folder: `4.摆正+识别/`

Generated by `batch_read_copy_bai_copy.py`.

Contents / 内容：

- `summary.csv` — overall results / 总体结果
- One subfolder per image / 每张图片一个子文件夹

`summary.csv` columns:

| Column | Meaning |
|---|---|
| image | Image file name |
| value | Predicted reading |
| human_value | Human-annotated true value |
| angle_rad | Pointer angle in radians |
| success | Whether recognition succeeded (`yes`/`no`) |
| output_dir | Path to the result subfolder |
| message | Error message if failed |

Each subfolder contains:

- `01_original.jpg`
- `02_aligned_to_template.jpg`
- `03_result_on_aligned.jpg`
- `04_pointer_mask.jpg`

---

## 5. Comparison Results / 对比结果

Folder: `对比/`

Contains outputs from `batch_compare_readers.py`.

`reader_comparison_results_2/metrics.csv` columns:

| Column | Meaning |
|---|---|
| method | Method name |
| success_rate | Success rate |
| mae | Mean absolute error |
| rmse | Root mean square error |
| max_error | Maximum absolute error |
| accuracy_within_0.05 | Ratio of errors ≤ 0.05 |
| avg_time_ms | Average runtime in milliseconds |

---

## 6. Special Folder: 3_3/ yes and no / 特殊文件夹：3_3/ yes 与 no

The folder `4.摆正+识别/3_3/` contains `yes/` and `no/` subfolders.
These are examples of successful (`yes`) and failed (`no`) alignment cases.
They are useful for debugging and for the paper figures.

---
